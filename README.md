# VideoDownloader (macOS, SwiftUI)

Нативное приложение для macOS: вставляешь ссылку на видео (**YouTube, VK** и
[сотни других сайтов](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md))
— получаешь `.mp4` с видеокодеком **H.264 (avc1)** и звуком AAC. Само приложение
— удобная оболочка вокруг **yt-dlp** (скачивание) и **ffmpeg** (склейка потоков,
перекодирование).

## yt-dlp и ffmpeg

**Они вшиты в приложение.** При сборке build-фаза `Scripts/bundle-tools.sh`
скачивает их в `VideoDownloader.app/Contents/Resources/bin/`:

- `yt-dlp` — standalone-сборка `yt-dlp_macos` (со своим Python, ничего не требует);
- `ffmpeg` — статическая сборка под нужную архитектуру
  ([eugeneware/ffmpeg-static](https://github.com/eugeneware/ffmpeg-static)).

Тому, кому отдашь `.app`, **ничего ставить не надо**. Приложение при первом
запуске снимает с этих бинарников карантин Gatekeeper само.

Обновление (внизу окна, кнопка **«Обновить yt-dlp»**) вызывает `yt-dlp -U` —
бинарник обновляет сам себя. Работает, если `.app` лежит в папке, куда есть право
записи (`~/Applications`, «Загрузки», рабочий стол; в `/Applications` без прав
администратора — нет).

### Запасной путь — системные yt-dlp/ffmpeg

Если встроенных бинарников нет (например, собрал без сети) — приложение ищет их в
`/opt/homebrew/bin`, `/usr/local/bin`, `/opt/local/bin`, `~/.local/bin`, `~/bin`
и через `which`, а кнопки «Установить/Обновить» работают через **Homebrew**
(`brew install/upgrade yt-dlp ffmpeg`). Можно указать путь вручную кнопкой
«Указать…».

## Видео, требующие входа (возрастные / приватные / для участников)

Всё автоматически. При скачивании приложение:

1. пробует без cookies (обычные видео так и качаются);
2. если YouTube просит вход — по очереди пробует cookies из установленных
   браузеров: **Safari**, Chrome, Firefox, Яндекс;
3. запоминает, что сработало, и в следующий раз пробует это первым.

Единственное, что нельзя сделать за пользователя, — выдать **Полный доступ к
диску** (это защита macOS). Он нужен, только чтобы прочитать cookies **Safari**.
Если приложение упрётся в это, оно покажет плашку с кнопками «Открыть настройки»
и «Показать приложение» — добавьте `.app` в список, перезапустите, повторите.
Доступ привязан к пути `.app`, поэтому держите копию в `/Applications` и
запускайте её, а не сборку из Xcode.

Если ни в одном браузере нет входа в YouTube — такое видео скачать нельзя ничем.

## Сборка

Нужен **Xcode** (не только Command Line Tools).

- Открой `YouTubeDownloader.xcodeproj`, выбери схему `YouTubeDownloader`, ⌘R.
  (Проект/схема называются `YouTubeDownloader` — историческое; собранное
  приложение — **`VideoDownloader.app`**, bundle id `com.yaroslavlukyanov.VideoDownloader`.)
- Или из терминала:

  ```bash
  xcodebuild -project YouTubeDownloader.xcodeproj -scheme YouTubeDownloader -configuration Release build
  ```

  Готовый `VideoDownloader.app` окажется в `~/Library/Developer/Xcode/DerivedData/…/Build/Products/Release/`.

**Первая сборка требует интернета** — build-фаза качает `yt-dlp` и `ffmpeg`
(~70 МБ) в бандл. Дальше они кэшируются внутри собранного `.app`; чтобы обновить
вшитые версии — Product → Clean Build Folder (⇧⌘K) и собрать заново.

Подпись для себя не нужна (Xcode подпишет «Sign to Run Locally»).

## Раздача друзьям

1. **Product → Clean Build Folder (⇧⌘K)** — обязательно, иначе ffmpeg останется
   только под текущую архитектуру.
2. Схему переключить на **Release**, затем **Product → Build (⌘B)**.
3. В терминале:
   ```bash
   sh "Scripts/package.sh"
   ```
   Скрипт сам находит свежий `VideoDownloader.app` в DerivedData, ad-hoc
   подписывает его, проверяет что `yt-dlp`/`ffmpeg` внутри и universal, и кладёт
   на рабочий стол:
   - **`VideoDownloader.zip`** — простой архив;
   - **`VideoDownloader.dmg`** — окно со стрелкой → «Программы» (фон
     `Scripts/dmg-background.png`, генерится `make-dmg-background.swift`).

   Первый запуск скрипта может спросить разрешение «Терминал → управление Finder»
   (для раскладки окна DMG) — разрешить. Без разрешения DMG всё равно соберётся,
   просто без стрелки.
   (Путь можно указать явно: `sh Scripts/package.sh /path/to/VideoDownloader.app`.)

**Как пересылать:** не через Telegram/WhatsApp — они пересжимают файлы и слетают
атрибуты, из-за которых macOS потом считает приложение «повреждённым» (это
реально случилось — Telegram подбил `.app`). Лучше AirDrop, облако (Google
Drive / Яндекс.Диск) или прямая ссылка.

Приложение **не нотаризовано** (нужен платный Apple Developer, $99/год), поэтому
друг при первом запуске:

- правый клик по `.app` → **Открыть** → **Открыть**; либо
- если пишет «не удаётся открыть» / «повреждено» — в Терминале:
  ```bash
  xattr -cr /Applications/VideoDownloader.app
  ```
- если и это не помогло — **Системные настройки → Конфиденциальность и
  безопасность** → внизу будет строка про заблокированный VideoDownloader →
  **«Открыть в любом случае»**.

Дальше ставить ничего не надо — yt-dlp и ffmpeg внутри, работает на Intel и
Apple Silicon. Для видео «с входом» приложение само попросит выдать ему
«Полный доступ к диску».

## Как работает выбор формата

yt-dlp запускается примерно так:

```
yt-dlp --newline --no-color --no-playlist --ignore-config \
  --ffmpeg-location <dir> \
  -f "bv*[height<=1080][vcodec^=avc1]+ba[ext=m4a]/bv*[height<=1080]+ba/b[height<=1080]/b" \
  -S "vcodec:h264,ext:mp4,res,br" \
  --merge-output-format mp4 --remux-video mp4 \
  -o "<папка>/%(title)s (VideoDownloader) %(width)sx%(height)s.%(ext)s" \
  <URL>
```

- Результат **всегда `.mp4` с кодеком H.264** — без всяких галок:
  1. формат-селектор берёт готовый H.264-поток, если он есть (тогда 0 перекодирования);
  2. `--merge-output-format mp4` + `--remux-video mp4` гарантируют mp4-контейнер;
  3. после скачивания приложение прогоняет `ffmpeg -i` по файлу и, если видео
     оказалось VP9/AV1 (бывает на 4K), **само перекодирует в H.264**
     (`libx264 -crf 20`, звук → AAC) и заменяет файл. Прогресс виден в статусе.

## Файлы

| Файл | Назначение |
|------|-----------|
| `YouTubeDownloaderApp.swift` | точка входа, окно |
| `ContentView.swift` | весь UI: поле ссылки, качество, папка, прогресс, журнал |
| `DownloadManager.swift` | запуск `yt-dlp`/`brew` через `Process`, разбор прогресса, отмена |
| `ToolLocator.swift` | поиск `yt-dlp` / `ffmpeg` (сначала внутри бандла, потом в системе) |
| `Scripts/bundle-tools.sh` | build-фаза: качает `yt-dlp` и `ffmpeg` в бандл |


## Замечания

- App Sandbox выключен намеренно — иначе запуск сторонних бинарников и запись в
  произвольную папку невозможны. Для личного инструмента это нормально; в Mac App
  Store такое не выложить.
- Скачивай только то, на что у тебя есть право (свои видео, материалы под
  свободной лицензией, разрешённое правообладателем).
